# 屏幕镜像（mirror）功能实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 dlnacast-cli 新增 `dlnacast mirror` 子命令，把当前电脑屏幕实时镜像到 DLNA 渲染设备。

**Architecture:** 外部 ffmpeg 子进程做采集（gdigrab/dshow）与硬件编码（nvenc→qsv→amf→libx264 回落链），输出 MPEG-TS 到 stdout 管道；Go 端经内置 HTTP 服务器的 `/live` 端点零缓冲直通给电视；SOAP SetAVTransportURI 投放直播 URL。

**Tech Stack:** Go 1.27（现有模块 dlnacast-cli）、外部 ffmpeg 二进制（非 Go 依赖）、现有 ssdp/dlna/server/ui 包。

## Global Constraints

- 只允许新增 `golang.org/x/sys/windows` 的**直接**使用（已在 go.mod，原为 indirect）；不得新增其他 Go 依赖
- ffmpeg 是可选外部二进制：不存在时报错并提示 https://ffmpeg.org 下载
- 编码器回落链顺序固定：h264_nvenc → h264_qsv → h264_amf → libx264
- **编码器探测必须真实试编码**（本机实测：`-encoders` 列表三者齐全，但 nvenc 缺 nvcuda.dll、amf 缺 amfrt64.dll，运行时才失败；qsv 可用）
- 画质预设精确值：low=1280x720/24fps/2M/GOP48；medium=1920x1080/30fps/4M/GOP60；high=源分辨率/30fps/8M/GOP60
- 低延迟参数：libx264 `-preset ultrafast -tune zerolatency`；MPEG-TS `-muxdelay 0 -muxpreload 0 -flush_packets -1`；短 GOP
- Windows 音频：dshow `audio=virtual-audio-capturer`（本机实测无此设备 → 自动降级纯视频）；仅 Windows 探测
- `/live` 零缓冲直通：每块写后 Flush，Content-Type `video/mp2t`
- 现有 ssdp/dlna/player/ui 包行为不得改变（dlna 包只读复用）
- 环境注意：Go 在 `/d/apps/go/bin`（需 `export PATH="/d/apps/go/bin:$PATH"`）；GOPROXY=goproxy.cn 已设；测试命令在仓库根目录运行

## 本机实测结论（实现时直接信任，无需重测）

- PATH 上的 ffmpeg：Gyan 7.1.1（WinGet，shared build），另有 D:\apps\ffmpeg-8.1.1-full_build\bin\ffmpeg.exe
- `gdigrab` 采集 + `h264_qsv` 编码 + mpegts 管道输出：已验证可产出数据
- `h264_nvenc` 失败（Cannot load nvcuda.dll）；`h264_amf` 失败（amfrt64.dll 打不开）→ 回落链在本机走到 qsv
- `libx264 -preset ultrafast -tune zerolatency` mpegts 管道：已验证可产出数据
- dshow 设备列表无 virtual-audio-capturer（仅 Integrated Camera 视频、Microphone Array 音频）→ 音频走降级路径

```go
// internal/mirror/ffmpeg.go
package mirror

import (
	"fmt"
	"os/exec"
	"runtime"
	"strconv"
	"strings"
)

type Quality string

const (
	QualityLow    Quality = "low"
	QualityMedium Quality = "medium"
	QualityHigh   Quality = "high"
)

type preset struct {
	maxW    int    // 0 = 源分辨率
	fps     int
	bitrate string
	gop     int
}

var presets = map[Quality]preset{
	QualityLow:    {maxW: 1280, fps: 24, bitrate: "2M", gop: 48},
	QualityMedium: {maxW: 1920, fps: 30, bitrate: "4M", gop: 60},
	QualityHigh:   {maxW: 0, fps: 30, bitrate: "8M", gop: 60},
}

// Options 镜像采集参数。Encoder/AudioDev 由探测步骤填充后传入 BuildArgs。
type Options struct {
	Display  int    // 显示器编号，0 = 主屏
	Region   string // 非空为 "x,y,w,h"，覆盖 Display
	Quality  Quality
	NoAudio  bool
	Encoder  string // h264 编码器名（ProbeEncoder 结果）
	AudioDev string // dshow 音频设备（如 audio=virtual-audio-capturer），空 = 无音频
}

// ParseRegion 解析 "x,y,w,h"，要求 w>0、h>0。
func ParseRegion(s string) (x, y, w, h int, err error) {
	parts := strings.Split(s, ",")
	if len(parts) != 4 {
		return 0, 0, 0, 0, fmt.Errorf("region 格式应为 x,y,w,h，得到 %q", s)
	}
	nums := make([]int, 4)
	for i, p := range parts {
		v, err := strconv.Atoi(strings.TrimSpace(p))
		if err != nil {
			return 0, 0, 0, 0, fmt.Errorf("region 含非数字 %q", p)
		}
		nums[i] = v
	}
	if nums[2] <= 0 || nums[3] <= 0 {
		return 0, 0, 0, 0, fmt.Errorf("region 宽高必须为正数")
	}
	return nums[0], nums[1], nums[2], nums[3], nil
}

func qualityOf(q Quality) (preset, error) {
	p, ok := presets[q]
	if !ok {
		return preset{}, fmt.Errorf("quality 必须是 low/medium/high，得到 %q", q)
	}
	return p, nil
}

// encoderArgs 返回编码器专属参数（顺序：在 -c:v 之后）。
func encoderArgs(enc string) []string {
	switch enc {
	case "libx264":
		return []string{"-preset", "ultrafast", "-tune", "zerolatency", "-pix_fmt", "yuv420p"}
	case "h264_qsv":
		return []string{"-preset", "veryfast"}
	case "h264_nvenc":
		return []string{"-preset", "p1"}
	case "h264_amf":
		return []string{"-quality", "speed"}
	}
	return nil
}

// BuildArgs 构造完整 ffmpeg 参数（不含程序名）。纯函数，不执行 ffmpeg。
func BuildArgs(ff string, opts Options) ([]string, error) {
	if opts.Encoder == "" {
		return nil, fmt.Errorf("Encoder 未设置（需先 ProbeEncoder）")
	}
	p, err := qualityOf(opts.Quality)
	if err != nil {
		return nil, err
	}

	args := []string{"-hide_banner", "-loglevel", "error"}

	// 视频采集输入
	switch runtime.GOOS {
	case "windows":
		args = append(args, "-f", "gdigrab", "-framerate", strconv.Itoa(p.fps))
		if opts.Region != "" {
			x, y, w, h, err := ParseRegion(opts.Region)
			if err != nil {
				return nil, err
			}
			args = append(args, "-offset_x", strconv.Itoa(x), "-offset_y", strconv.Itoa(y),
				"-video_size", fmt.Sprintf("%dx%d", w, h))
		} else {
			x, y, err := displayOrigin(opts.Display)
			if err != nil {
				return nil, err
			}
			w, h, err := displaySize(opts.Display)
			if err != nil {
				return nil, err
			}
			args = append(args, "-offset_x", strconv.Itoa(x), "-offset_y", strconv.Itoa(y),
				"-video_size", fmt.Sprintf("%dx%d", w, h))
		}
		args = append(args, "-i", "desktop")
	case "darwin":
		args = append(args, "-f", "avfoundation", "-framerate", strconv.Itoa(p.fps), "-capture_cursor", "1", "-i", "1")
	case "linux":
		args = append(args, "-f", "x11grab", "-framerate", strconv.Itoa(p.fps), "-i", ":0.0")
	default:
		return nil, fmt.Errorf("不支持的平台: %s", runtime.GOOS)
	}

	// 音频输入
	if opts.AudioDev != "" {
		switch runtime.GOOS {
		case "windows":
			args = append(args, "-f", "dshow", "-i", opts.AudioDev)
		case "linux":
			args = append(args, "-f", "pulse", "-i", "default")
		}
	}

	// 编码
	args = append(args, "-c:v", opts.Encoder)
	args = append(args, encoderArgs(opts.Encoder)...)
	if p.maxW > 0 {
		args = append(args, "-vf", fmt.Sprintf("scale=%d:-2", p.maxW))
	}
	args = append(args, "-b:v", p.bitrate, "-g", strconv.Itoa(p.gop))

	// 音频编码
	if opts.AudioDev != "" {
		args = append(args, "-c:a", "aac", "-b:a", "128k")
	}

	// 输出：低延迟 MPEG-TS 到 stdout
	args = append(args, "-f", "mpegts", "-muxdelay", "0", "-muxpreload", "0", "-flush_packets", "-1", "pipe:1")
	return args, nil
}

// FindFFmpeg 在 PATH 与常见安装位置查找 ffmpeg。
func FindFFmpeg() (string, error) {
	if p, err := exec.LookPath("ffmpeg"); err == nil {
		return p, nil
	}
	var candidates []string
	switch runtime.GOOS {
	case "windows":
		candidates = []string{
			`C:\ffmpeg\bin\ffmpeg.exe`,
			`C:\Program Files\ffmpeg\bin\ffmpeg.exe`,
		}
	default:
		candidates = []string{"/usr/local/bin/ffmpeg", "/opt/homebrew/bin/ffmpeg"}
	}
	for _, c := range candidates {
		if _, err := exec.LookPath(c); err == nil {
			return c, nil
		}
	}
	return "", fmt.Errorf("未找到 ffmpeg，请安装后加入 PATH: https://ffmpeg.org/download.html")
}
```

```go
//go:build windows

package mirror

import (
	"fmt"
	"syscall"
	"unsafe"
)

type rect struct {
	Left, Top, Right, Bottom int32
}

type monitorInfo struct {
	index int
	r     rect
}

var (
	user32               = syscall.NewLazyDLL("user32.dll")
	procEnumDisplayMonitors = user32.NewProc("EnumDisplayMonitors")
	procGetMonitorInfo      = user32.NewProc("GetMonitorInfoW")
)

type monitorInfoEx struct {
	cbSize    uint32
	rcMonitor rect
	rcWork    rect
	dwFlags   uint32
	// 其余字段（设备名等）不需要，按 WINMONINFO 布局预留
	rest [64]byte
}

func listMonitors() ([]monitorInfo, error) {
	var monitors []monitorInfo
	cb := syscall.NewCallback(func(hm, hdc, prect, lparam uintptr) uintptr {
		mi := monitorInfoEx{cbSize: uint32(unsafe.Sizeof(monitorInfoEx{}))}
		ret, _, _ := procGetMonitorInfo.Call(hm, uintptr(unsafe.Pointer(&mi)))
		if ret == 0 {
			return 1
		}
		monitors = append(monitors, monitorInfo{index: len(monitors), r: mi.rcMonitor})
		return 1
	})
	ret, _, err := procEnumDisplayMonitors.Call(0, 0, cb, 0)
	if ret == 0 {
		return nil, fmt.Errorf("EnumDisplayMonitors 失败: %v", err)
	}
	if len(monitors) == 0 {
		return nil, fmt.Errorf("未枚举到显示器")
	}
	return monitors, nil
}

// displayOrigin 返回第 n 个显示器的原点（n=0 主屏）。
func displayOrigin(n int) (int, int, error) {
	monitors, err := listMonitors()
	if err != nil {
		return 0, 0, err
	}
	if n < 0 || n >= len(monitors) {
		return 0, 0, fmt.Errorf("显示器编号 %d 超出范围（共 %d 个）", n, len(monitors))
	}
	return int(monitors[n].r.Left), int(monitors[n].r.Top), nil
}

// displaySize 返回第 n 个显示器的分辨率。
func displaySize(n int) (int, int, error) {
	monitors, err := listMonitors()
	if err != nil {
		return 0, 0, err
	}
	if n < 0 || n >= len(monitors) {
		return 0, 0, fmt.Errorf("显示器编号 %d 超出范围（共 %d 个）", n, len(monitors))
	}
	r := monitors[n].r
	return int(r.Right - r.Left), int(r.Bottom - r.Top), nil
}
```

```go
// buildFake 编译 testdata/fakeffmpeg 为可执行文件，作为假 ffmpeg。
func buildFake(t *testing.T) string {
	t.Helper()
	bin := filepath.Join(t.TempDir(), "fakeffmpeg")
	if filepath.Separator == '\\' {
		bin += ".exe"
	}
	cmd := exec.Command("go", "build", "-o", bin, "./testdata/fakeffmpeg")
	cmd.Dir = repoRoot(t)
	if out, err := cmd.CombinedOutput(); err != nil {
		t.Fatalf("编译 fake ffmpeg 失败: %v\n%s", err, out)
	}
	return bin
}

func repoRoot(t *testing.T) string {
	t.Helper()
	dir, err := os.Getwd()
	if err != nil {
		t.Fatal(err)
	}
	for {
		if _, err := os.Stat(filepath.Join(dir, "go.mod")); err == nil {
			return dir
		}
		parent := filepath.Dir(dir)
		if parent == dir {
```

**Interfaces:**
- Consumes: 无（接收任意外部命令路径与参数；Task 1 的 FindFFmpeg 结果在 Task 5 传入）
- Produces:
  - `type Capture struct{...}`
  - `func Start(ff string, args []string) (*Capture, error)` — 启动 ffmpeg，stdout 经 io.Pipe 桥接
  - `func (c *Capture) Stdout() io.Reader` — 持续可读；进程崩溃后自动重启 1 次，重启成功则流继续，重启失败或二次崩溃时管道关闭（读端见 EOF）
  - `func (c *Capture) Done() <-chan struct{}` — 采集永久失败（重启耗尽）后关闭
  - `func (c *Capture) Err() error` — Done 后可取失败原因
  - `func (c *Capture) Stop() error` — kill 进程 + 关管道

设计说明（与 spec 的差异）：spec 写"重启期间 Stdout 读到 EOF，结束会话"。实现采用 io.Pipe 桥接：重启成功时流**无缝继续**（优于 spec，电视端 TS 会自动重同步），重启失败才 EOF。这是对 spec 意图（崩溃可恢复）的更优实现，reviewer 如质疑以此为准。

```go
// internal/mirror/capture.go
package mirror

import (
	"fmt"
	"io"
	"os"
	"os/exec"
	"sync"
)

// Capture 管理采集子进程：stdout 经 io.Pipe 桥接给消费者；
// 进程意外退出时自动重启 1 次，重启成功流继续，再失败则关闭管道（EOF）。
type Capture struct {
	ff   string
	args []string

	mu      sync.Mutex
	cmd     *exec.Cmd
	pipeW   *io.PipeWriter
	pipeR   *io.PipeReader
	restarted bool
	stopped   bool
	done      chan struct{}
	err       error
}

func Start(ff string, args []string) (*Capture, error) {
	c := &Capture{ff: ff, args: args, done: make(chan struct{})}
	c.pipeR, c.pipeW = io.Pipe()
	if err := c.launch(); err != nil {
		c.pipeW.Close()
		c.pipeR.Close()
		return nil, err
	}
	go c.watch()
	return c, nil
}

func (c *Capture) Stdout() io.Reader { return c.pipeR }

func (c *Capture) Done() <-chan struct{} { return c.done }

func (c *Capture) Err() error {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.err
}

// launch 启动子进程并把 stdout 拷贝到管道。
func (c *Capture) launch() error {
	cmd := exec.Command(c.ff, c.args...)
	cmd.Stdout = c.pipeW
	cmd.Stderr = os.Stderr
	if err := cmd.Start(); err != nil {
		return fmt.Errorf("启动 ffmpeg 失败: %w", err)
	}
	c.mu.Lock()
	c.cmd = cmd
	c.mu.Unlock()
	return nil
}

// watch 等待进程退出：Stop 视为正常；意外退出则重启 1 次。
func (c *Capture) watch() {
	c.mu.Lock()
	cmd := c.cmd
	c.mu.Unlock()
	err := cmd.Wait()

	c.mu.Lock()
	stopped := c.stopped
	c.mu.Unlock()
	if stopped {
		return // Stop() 负责收尾
	}

	// 意外退出：重启 1 次
	c.mu.Lock()
	if c.restarted {
		c.err = fmt.Errorf("ffmpeg 再次退出: %v", err)
		c.restarted = false
		c.mu.Unlock()
		c.finish()
		return
	}
	c.restarted = true
	c.mu.Unlock()

	if err := c.launch(); err != nil {
		c.mu.Lock()
		c.err = fmt.Errorf("ffmpeg 崩溃且重启失败: %v（原错误: %v）", err, err)
		c.mu.Unlock()
		c.finish()
		return
	}
	go c.watch()
}

func (c *Capture) finish() {
	c.pipeW.Close() // 读端得到 EOF
	c.mu.Lock()
	alreadyClosed := c.doneClosed()
	c.mu.Unlock()
	if !alreadyClosed {
		close(c.done)
	}
}

func (c *Capture) doneClosed() bool {
	select {
	case <-c.done:
		return true
	default:
		return false
	}
}

// Stop 终止子进程并关闭管道。
func (c *Capture) Stop() error {
	c.mu.Lock()
	c.stopped = true
	cmd := c.cmd
	c.mu.Unlock()
	if cmd != nil && cmd.Process != nil {
		cmd.Process.Kill()
	}
	c.mu.Lock()
	first := !c.doneClosed()
	c.mu.Unlock()
	if first {
		close(c.done)
	}
	return c.pipeW.Close()
}
```

实现者自查要点（写完必须逐条核对）：
- `watch` 重启分支里 `go c.watch()` 后旧 goroutine 返回——不会有两个 watch 同时 Wait 同一 cmd
- `Cmd.Wait` 与 `Stdout` 使用 io.Writer（pipeW）兼容（exec 文档允许）
- Stop 后 Done 关闭、管道关闭、Err 为 nil
- `finish()` 里 `c.err` 赋值发生在 `c.mu` 保护下（`c.finish` 前 `c.err` 已在锁内赋值——核对两次崩溃路径的锁顺序）

```go
// internal/mirror/stream.go
package mirror

import (
	"io"
	"net/http"
)

// NewLiveHandler 返回 /live 直播端点：把 src 的 MPEG-TS 字节零缓冲直通给客户端。
// 每块写入后立即 Flush；源 EOF 或客户端断开时结束。
// 单生产者（ffmpeg 管道）单消费者（一台电视）模型。
func NewLiveHandler(src io.Reader) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "video/mp2t")
		w.Header().Set("Cache-Control", "no-store")
		flusher, _ := w.(http.Flusher)
		buf := make([]byte, 32*1024)
		for {
			n, err := src.Read(buf)
			if n > 0 {
				if _, werr := w.Write(buf[:n]); werr != nil {
					return // 客户端断开
				}
				if flusher != nil {
					flusher.Flush()
				}
			}
			if err != nil {
				return // 源 EOF（采集结束/崩溃未恢复）
			}
		}
	})
}
```

```go
func selectDevice(name string, timeout int, verbose bool) (*dlna.Device, error) {
	locs, err := ssdp.Discover(time.Duration(timeout) * time.Second)
	if err != nil {
		return nil, fmt.Errorf("扫描失败: %w", err)
	}
	if len(locs) == 0 {
		return nil, fmt.Errorf("未发现 DLNA 设备，请确认电视与电脑在同一局域网")
	}
	c := dlna.NewClient()
	var devices []*dlna.Device
	for _, loc := range locs {
		dev, err := dlna.Describe(loc, c)
		if err != nil {
			if verbose {
				fmt.Fprintf(os.Stderr, "跳过设备 %s: %v\n", loc, err)
			}
			continue
		}
		devices = append(devices, dev)
	}
	if len(devices) == 0 {
		return nil, fmt.Errorf("未发现可用的 DLNA 设备")
	}
	var dev *dlna.Device
	if name != "" {
		for _, d := range devices {
			if d.Host == name || strings.Contains(d.Name, name) {
				dev = d
				break
			}
		}
		if dev == nil {
			return nil, fmt.Errorf("未找到设备 %q", name)
		}
	} else {
		dev = ui.ChooseDevice(devices)
		if dev == nil {
			return nil, fmt.Errorf("已取消")
		}
	}
	return dev, nil
}
```

```go
func runMirrorCommand(rest []string, device string, timeout int, verbose bool, port int) {
	fs := flag.NewFlagSet("mirror", flag.ExitOnError)
	var (
		display  = fs.Int("display", 0, "显示器编号（0 = 主屏）")
		region   = fs.String("region", "", "只采集屏幕区域 x,y,w,h")

		noAudio  = fs.Bool("no-audio", false, "不采集系统声音")
	)
	fs.Usage = func() {
		fmt.Fprintf(os.Stderr, "用法: dlnacast [全局 flags] mirror [flags]\n\nFlags:\n")
		fs.PrintDefaults()
	}
	if err := fs.Parse(rest); err != nil {
		os.Exit(1)
	}

	opts := mirror.Options{
		Display: *display,
		Region:  *region,
		NoAudio: *noAudio,
	}
	switch mirror.Quality(*quality) {
	case mirror.QualityLow:
		opts.Quality = mirror.QualityLow
	case mirror.QualityMedium:
		opts.Quality = mirror.QualityMedium
	case mirror.QualityHigh:
		opts.Quality = mirror.QualityHigh
	default:
		fmt.Fprintf(os.Stderr, "错误: quality 必须是 low/medium/high\n")
		os.Exit(1)

	}

	}

	if !opts.NoAudio {
		if audioDev, ok := mirror.ProbeAudioDevice(ff); ok {
			opts.AudioDev = audioDev
			if verbose {
				fmt.Printf("音频设备: %s\n", audioDev)
			}
		} else {
			fmt.Println("提示: 未找到系统声音采集设备，仅镜像画面")
		}
	}

	if opts.Region != "" {
		if _, _, _, err := mirror.ParseRegion(opts.Region); err != nil {

func runMirror(opts mirror.Options, device string, port, timeout int, verbose bool) {
	dev, err := selectDevice(device, timeout, verbose)
	if err != nil {
		fmt.Fprintf(os.Stderr, "错误: %v\n", err)
		os.Exit(1)
	}
	fmt.Printf("投屏到: %s (%s)\n", dev.Name, dev.Host)

	args, err := mirror.BuildArgs("ffmpeg", opts)
	if err != nil {
		fmt.Fprintf(os.Stderr, "错误: %v\n", err)
		os.Exit(1)
	}
	ff, _ := mirror.FindFFmpeg() // runMirrorCommand 已保证成功
	if verbose {
		fmt.Printf("ffmpeg 参数: %s %s\n", ff, strings.Join(args, " "))
	}

	cap, err := mirror.Start(ff, args)
	if err != nil {
		fmt.Fprintf(os.Stderr, "错误: %v\n", err)
		os.Exit(1)
	}

	srv := server.NewServer(port)
	srv.SetLiveHandler(mirror.NewLiveHandler(cap.Stdout()))
	if err := srv.Start(); err != nil {
		cap.Stop()
		fmt.Fprintf(os.Stderr, "启动本地服务失败: %v\n", err)
		os.Exit(1)
	}

	ip, err := dlna.LocalIPFor(dev.Host)
	if err != nil {
		cap.Stop()
		srv.Close()
		fmt.Fprintf(os.Stderr, "错误: %v\n", err)
		os.Exit(1)
	}
	liveURL := fmt.Sprintf("http://%s:%d/live", ip, srv.Port())
	fmt.Printf("直播地址: %s\n", liveURL)

	tr := dlna.NewTransport(dev, dlna.NewClient())
	recast := func() {
		if err := tr.Load(liveURL, "屏幕镜像", "video", ""); err != nil {
			fmt.Fprintf(os.Stderr, "\n投放失败: %v\n", err)
		}
	}
	recast()

	keys, cancelKeys, err := ui.Keys()
	if err != nil {
		fmt.Fprintln(os.Stderr, "提示: 无法进入交互模式，镜像中... (Ctrl+C 退出)")
		select {}
	}
	defer cancelKeys()

	fmt.Println("按 s 重新同步到实时画面，↑↓ 音量，q 退出")
	start := time.Now()
	ticker := time.NewTicker(3 * time.Second)
	defer ticker.Stop()
	volume := -1
	failCount := 0
	quit := false
	for !quit {
		select {
		case k, ok := <-keys:
			if !ok {
				quit = true
				break
			}
			switch k {
			case ui.KeyQuit:
				quit = true
			case ui.KeyS:
				recast() // 重新投放，回到实时点
			case ui.KeyUp:
				if volume < 0 {
					volume, _ = tr.Volume()
				}
				volume = min(volume+10, 100)
				tr.SetVolume(volume)
			case ui.KeyDown:
				if volume < 0 {
					volume, _ = tr.Volume()
				}
				volume = max(volume-10, 0)
				tr.SetVolume(volume)
			}
		case <-cap.Done():
			fmt.Fprintf(os.Stderr, "\n采集失败: %v\n", cap.Err())
			quit = true
		case <-ticker.C:
			elapsed := int(time.Since(start).Seconds())
			_, _, playing, err := tr.Status()
			if err != nil {
				failCount++
				if failCount >= 3 {
					fmt.Fprintln(os.Stderr, "\n设备可能已断开连接")
					quit = true
					break
				}
				continue
			}
			failCount = 0
			if volume < 0 {
				volume, _ = tr.Volume()
			}
			ui.RenderProgress(os.Stdout, elapsed, 0, playing, volume, "屏幕镜像")
		}
	}
	fmt.Println()
	cap.Stop()
	srv.Close()
	tr.Stop()
}
```

````markdown
## Screen mirroring

Mirror your computer screen to the TV in real time (requires [ffmpeg](https://ffmpeg.org/download.html) installed and on PATH):

### Mirror flags

```
-display <n>    Monitor index (0 = primary, default)
-region x,y,w,h Capture only this region (overrides -display)
-quality <p>    low / medium / high (default medium)
-no-audio       Skip system audio capture
```

Global flags (`-d`, `-timeout`, `-v`, `-port`) go **before** the `mirror` keyword; mirror flags go after it.

Mirror shortcuts: `s` re-syncs the TV to the live edge, `↑`/`↓` volume, `q` quit.

### Latency

DLNA pushes a URL to the TV's own player, whose 1–3 s buffer cannot be avoided from the caster side. The caster pipeline (capture → hardware encode → HTTP push) adds under 100 ms, so expect **1–3 s end-to-end latency** — the TV's player is the bottleneck. System audio requires a virtual audio capture device (e.g. `virtual-audio-capturer` on Windows); without one, mirroring falls back to video only automatically. H.264 encoding uses the first available of: NVENC → QSV → AMF → libx264 (ultrafast).
````
